# Strata · 岩层 / 0.1 视觉验证目标

这是一张工作台，验证同一组件结构在五组明暗主题下的气质。不是生产规范，也不是 Apple 官方设计系统。参考经典 iMac / iPhone 5C 糖果色的亲和力，以自定义配色和哑光中性色重新表达。

- 最大内容宽 1232px；桌面双列，手机单列；同一主题变体不改变结构与尺寸。
- 页面 → 内容区 → 卡片使用明度层次；没有玻璃模糊、渐变、霓虹或阴影。
- 基线正文 14px；标题 32px；元信息 11–12px；间距 4/8/12/16/24/32。
- 控件高 40px、圆角 8px；卡片 12px；区块 16px。所有共享值在 tokens.mjs。
- 糖果原色只用于色板和主题样本。浅色主按钮使用深品牌色配白字；深色使用浅品牌色配深字。
- 品牌、状态、图表各用独立语义 token；列表选中以中性表面、勾号和「已选」表达。
- 明暗分别校准；普通文字对实际表面至少 4.5:1；可见焦点环，不靠颜色独自表达状态。
- 统计是明确标注的模拟数据，只用一条独立图表色进度条表达比例。
- 保持可复现 URL；支持 reduced motion；没有账号、后端或远程字体。

初始问题：尚无应用与 tokens，因此本次为从零建立参考画面，没有旧版 UI 可供比较。方向最终是否成立由使用者评估；首版仅报告渲染与交互的可验证结果。
