# Strata · 岩层 / 0.2 Glass 主题规则

继续使用同一组件工作台和五组明暗主题，增加通透材质与圆润轮廓。配色受到经典 iMac / iPhone 5C 启发，材质采用网页 Glass 表达；均为自定义设计，不宣称为 Apple 官方系统或原生 Liquid Glass。仍是主题验证原型。

## 布局与形状

- 最大内容宽 1232px；桌面双列、手机单列；配色和材质切换都保持结构、尺寸不变。
- 正文 14px，标题 32px，元信息 11–12px；间距 4/8/12/16/24/32。
- 按钮、分段开关使用胶囊轮廓，色板为圆形；普通控件圆角 16px、内容卡片 24px、外层容器 32px。控件高 40px。
- 420px 及以下屏幕的内容卡片使用单列，保留 16px 内边距，避免圆角挤压文字。
- 颜色、材质、圆角等共享值都在 tokens.mjs；界面规格标签读取当前 tokens。

## Glass 材质

- 页面保留低饱和中性底色，只添加静态品牌色形作为折光背景。没有霓虹、动态光斑、鼠标追随折射或铺满页面的渐变。
- 外层面板承载 blur 24px / saturation 125% 和半透明填充；内层阅读表面更实，不叠加多层 backdrop blur。
- 浅色面板 / 内容 / 控件不透明度为 62% / 70% / 64%；深色分别为 72% / 82% / 85%。深色单独校准，不能机械反色。
- 通过细边缘、顶部高光和低强度接触阴影表达玻璃厚度。渐变只用于材质高光；主按钮保持实色，保证文字对比。
- 内层描边弱于外层（深色约 9% / 16% 白色），减少重复轮廓；手机背景色形强度为桌面的 65%。
- 主按钮使用可读的实色与文字配对；品牌色、状态色、图表色独立。普通列表选中仍使用中性表面、勾号和「已选」。
- 校验文字与实际合成背景的对比度，普通文字目标至少 4.5:1；不能只检查 alpha 叠加前的色值。

## 回退与交互

- 顶部「玻璃 / 实底」按钮切换材质，并将 `material=glass|solid` 保留在 URL。
- 系统 `prefers-reduced-transparency: reduce` 或浏览器不支持 backdrop-filter 时，强制实底、关闭背景色形、模糊、高光和阴影；JSON 导出反映实际生效的材质。
- `prefers-reduced-motion` 停止动画，加载保留文字；键盘焦点至少 3px，状态不只依赖颜色。
- Button、Card、List 继续使用明确标注的演示内容，无账号、后端、业务数据或外部网络请求。

## 本轮评估

方向在上一版基础上向更圆润、通透的 Glass 演进。0.1 哑光截图仍保留在 design/screenshots/ 根目录；0.2 在 glass/ 子目录。是否继续加深通透程度与色彩表现，仍由使用者判断，不据此建立生产规范。
